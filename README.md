## 🚀 代表项目

### 🛸 室内自主目标搜索无人机

基于 **ROS 2 + PX4 + SLAM + YOLO** 构建的室内自主探索与目标搜索无人机系统。

主要功能：

- 基于 Frontier 的自主探索
- 实时 SLAM 建图与栅格地图构建
- 基于 YOLO 的目标检测
- A* 全局路径规划
- 局部避障与轨迹控制
- PX4 Offboard 自主飞行控制

**技术栈：**

`ROS 2` · `PX4` · `Gazebo` · `slam_toolbox` · `YOLO` · `OpenCV` · `A*` · `MPC`

> 项目代码正在整理中。
